# Install VidPrompt

VidPrompt @APP_VERSION@ requires macOS @MINIMUM_MACOS@ or later. The main app executable supports **@MAIN_ARCHITECTURES@**; the bundled command-line helper supports **@CLI_ARCHITECTURES@**. It is a preview build and has not been signed with Developer ID or notarised, so macOS may show a security warning.

1. Open the downloaded `VidPrompt @APP_VERSION@.dmg`.
2. Drag `VidPrompt.app` onto the `Applications` shortcut in the window.
3. Eject the VidPrompt disk image, then open VidPrompt from Applications.

If you prefer to keep apps in a named folder, create that folder inside Applications first and drag VidPrompt there instead.

If macOS says it cannot verify the developer, first try opening VidPrompt once. Then open **System Settings > Privacy & Security**, scroll to Security and choose **Open Anyway** for VidPrompt. Confirm the next prompt only if you trust the copy you downloaded. Apple cautions that overriding this warning carries risk; this build has not been reviewed by Apple. Do not remove quarantine attributes or bypass Gatekeeper in Terminal.

Allow camera or microphone access when you use those features. VidPrompt keeps scripts in your user account; the disk image contains only the app.

Apple's instructions: [Open a Mac app from an unknown developer](https://support.apple.com/en-jo/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).
